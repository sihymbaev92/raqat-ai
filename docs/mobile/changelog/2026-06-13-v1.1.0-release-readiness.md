## Release Theme

`v1.1.0` moves the app from feature growth into a cleaner release candidate: safer namaz/azan behavior, smoother dashboard visuals, and crash-free core navigation on a real Android device.

## Included Changes

- Dashboard hero background was replaced with a smoother high-resolution prayer hero asset; the old low-resolution dome crop caused visible pixeling behind the home prayer card.
- Dashboard tile images now lazy-reveal with deterministic staggered timers, reducing initial image pressure without leaving lower rows blank for too long.
- Qibla motion settings now keep the stable mode path and no longer require the Qibla sensor provider inside Settings.
- Settings crash from `useQiblaMotion: QiblaSensorProvider жоқ` was fixed.
- Full-screen Azan deep links now preserve query params (`label`, `enteredTitle`, `time`, `soundId`, `salatKey`, `nativeAudio`), so the screen shows titles such as `Аср намазы кірді`.
- Full-screen Azan screen shows prayer title, time, azan text blocks, repeat counts, and the stop button.
- Qibla widget service stop calls now guard against unregistered service warnings in logcat.
- Kazakhstan prayer times use the official Muftyat source path where available, with fallback behavior preserved.
- Settings now includes a release diagnostics card showing app version/build, API liveness, notification permission, scheduled prayer/azan counts, exact alarm, and full-screen Azan readiness.
