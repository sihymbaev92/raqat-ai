Құрметті halaldamu.kz командасы!

Біз **RAQAT** (Қазақстандағы исламдық мобильді қосымша) жобасын әзірлеп жатырмыз. Қолданбада пайдаланушыларға **ресми халал реестр** деректерін көрсету мақсатында қазіргі уақытта сіздердің ашық WordPress JSON API (`/wp-json/halal-bot/v1/…`) пайдаланылуда:

- `GET /halal-bot/v1/companies` — сертификатталған ұйымдар каталогы  
- `GET /halal-bot/v1/companies/{id}` — ұйым карточкасы  
- `GET /halal-bot/v1/products` — өнімдер (штрихкод, іздеу)  
- `GET /halal-bot/v1/additives` — қосымшалар (E-кодтар)

Сұраулар **тек оқу режимінде**, деректерді қайта жариялаусыз, пайдаланушыға әрқашан **halaldamu.kz** ресми сайтына сілтеме беріледі.

## Біз не істедік

1. Мобильді клиентте штрихкод сканерлеу және реестрден автоматты іздеу.  
2. Желі нашар жерлер үшін жергілікті кэш (ұйымдар тізімі).  
3. Өз **platform API** прокси қабаты (бір User-Agent, серверлік кэш) — жүктемені бір шлюзден реттеу үшін.

## Сізден сұрайтындар

1. **Өнімдер дерекқоры (шұғыл)**  
   - 2026-05-19 тексеру: `GET /halal-bot/v1/products` және `?search=…` — **`items: []`**, `total: 0` (companies ~3757 жазба).  
   - `products` API-да деректер толықтырылу жоспары бар ма? Қашан штрихкод/атау бойынша іздеу іске қосылады?  
   - Штрихкод бойынша сыртқы интеграцияға арналған **ресми документация** немесе кеңейтілген өрістер бар ма?

2. **Rate limit және қолжетімділік**  
   - Қанша сұрау/минут (IP немесе API кілт) рұқсат етіледі?  
   - Жоғары жүктеме үшін (мысалы каталог синхрондау ~4 МБ JSON) **белгіленген кэш TTL** немесе CDN ұсына аласыз ба?

3. **Ресми ынтымақтастық**  
   - RAQAT-ты «ресми дерек көзі ретінде пайдаланатын» серіктес ретінде тіркеуге бола ма?  
   - Логотип/сілтеме алмасу және техникалық байланыс (email/Telegram) кімде?

4. **Келешек API**  
   - Webhook немесе `If-Modified-Since` / нұсқа нөмірі арқылы инкрементті жаңарту жоспарланбаған ба?
