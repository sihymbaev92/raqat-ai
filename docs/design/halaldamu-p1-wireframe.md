# Halal Damu — P1 wireframe (мобильді)

**Мақсаты:** бір экран — үш мақсат: **мекемелер**, **тексеру**, **карта**. Products API бос кезде де UX түсінікті.

## Жоғарғы құрылым

```
┌─────────────────────────────────────────┐
│  ХАЛАЛ ДАМУ          halaldamu.kz        │
│  [Ресми реестр] [Өнім тексеру]          │
├─────────────────────────────────────────┤
│ ┌─────────┬─────────┬─────────┐         │
│ │ Мекеме  │ Тексеру │  Карта  │  ← tabs │
│ └─────────┴─────────┴─────────┘         │
├─────────────────────────────────────────┤
│ ⚠ Өнімдер API: дерек жоқ (2026-05…)     │  ← status banner
│    Штрихкод — ұйым fallback. [Толығы]   │
├─────────────────────────────────────────┤
│  << tab content >>                      │
├─────────────────────────────────────────┤
│  Деректер ресми реестрден…             │
│  [↻] halaldamu.kz · 3757 мекеме         │
└─────────────────────────────────────────┘
```

## Tab 1 — Мекемелер

```
┌─ Жақын маңдағы ұйымдар / Өнім / Мешіт ─┐
│  Іздеу түрі: [Мекеме][Өнім][Мешіт]    │
│  Санат: Барлығы · Тамақ · …           │
│  🔍 Атау немесе мекенжай               │
│  [5 км][10 км]  [Іздеу]               │
│  ── нәтижелер тізімі ──                │
└───────────────────────────────────────┘

┌─ Ұйым каталогы ───────────────────────┐
│  🔍 Ұйым атауы (3+ таңба)              │
│  Соңғы іздеулер · Таңдаулылар          │
│  Сүзгілер (сертификат, санат)          │
│  Карточкалар тізімі + «келесі бет»     │
└───────────────────────────────────────┘
```

## Tab 2 — Тексеру

```
┌─ Халал тексеру ───────────────────────┐
│  Өнім күйі: Барлығы · Халал · …       │
│  🔍 Атау / E-код / штрихкод           │
│  [Сурет] [Штрихкод]                   │
│  Негізгі іздеу + AI сурет              │
│  ── нәтиже қорытындысы ──              │
│  Өнім · Қосымша · Ұйым карточкалары   │
│  Соңғы скан (офлайн)                  │
└───────────────────────────────────────┘
```

Өнім табынан «Тексеру»ге өту: `Іздеу түрі → Өнім` нәтижесін басып.

## Мониторинг (ops)

```bash
python scripts/check_halaldamu_products_api.py --fail-if-empty --json-out data/halaldamu-products-monitor.json
```

Cron (апта сайын): products `total > 0` болғанда командаға хабарлау.
