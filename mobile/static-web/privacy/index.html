Құпиялылық саясаты

RAHAT OMIR · kz.raqat.app · жаңартылған: 2026-07-18 · нұсқа 1.2.0

Тәуелсіздік: RAHAT OMIR — тәуелсіз жоба. ҚМДБ, Fatua.kz немесе Muftyat.kz ресми мобильді қолданбасы емес. Ресми сайттардан рұқсат бойынша индекстелген үзінділер көрсетіледі; толық мәтін — бастапқы сайтта.

Қолданба намаз уақыты, Құран, құбыла, халал анықтама және ресми діни дереккөздерге сілтеме береді. Генеративті AI чат / автоматты фетва жоқ. Жарнама желілеріне дерек сатпаймыз.

1. Қандай деректер жиналады

  • Орналасу (GPS) — құбыла және жергілікті намаз уақыты (рұқсат бергенде). Қаланы қолмен таңдауға болады.
  • Аккаунт — Google / Apple OAuth арқылы кіргенде (email/атау провайдерден); хатым/белгілерді синхрондау үшін.
  • Камера / сурет — тек халал/штрихкод тексеруін өзіңіз бастағанда.
  • Қолданба оқиғалары — экран/нұсқа/сессия идентификаторы (аноним); серверде IP хэштеледі. Баптаулардан өшіруге болады.
  • Қате есептері — құлау кезінде стек, маршрут, құрылғы моделі (жөндеу үшін).

Жарнама ID жиналмайды. Азан хабарламалары құрылғыда жергілікті жоспарланады.

2. Үшінші тараптар (ашық тізім)

  • api.rahatomir.com — аккаунт, синк, мониторинг
  • Muftyat.kz / Fatua.kz — ресми мақала индексі
  • api.muftyat.kz — ҚР намаз кестесі (басым)
  • api.aladhan.com — намаз уақыты резерві
  • islamic.network / alquran.cloud / Quran.com CDN — Құран мәтін/аудио
  • Google / Apple — кіру токені
  • live.net.sa — Қағба HLS эфир

3. Діни мазмұн

Пәтуа немесе үкім берілмейді. Намаз оқуы ғылыми шолу аяқталмайынша оқу материалы ретінде белгіленеді. Хадис қазақша мағынасы — тек сенімді каталогтағы жазбалар. Қоғамдық дұға жариялау модерациясыз өшірілген.

4. Пайдаланушы таңдауы

  • Орналасу, камера, хабарлама рұқсаттарын жүйеден өшіру
  • Баптаулар → «Қолданба статистикасы» өшіру
  • Аккаунтсыз негізгі мазмұн қолжетімді
  • Аккаунтты жою — Баптаулардағы шығу + қолдау арқылы сұрау
