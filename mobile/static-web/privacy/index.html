Құпиялылық саясаты

RAHAT OMIR · kz.raqat.app · жаңартылған: 2026-06-21 · нұсқа 1.1.0

RAHAT OMIR — намаз уақыты, Құран, құбыла, халал тексеру және AI көмекшісі бар исламдық қолданба. Біз деректерді тек қолданба функцияларын қамтамасыз ету үшін өңдейміз; жарнама желілеріне сатпаймыз.

1. Қандай деректер жиналады

  • Орналасу (GPS) — құбыла бағыты мен жергілікті намаз уақыты үшін (рұқсат бергенде). Қалады қолмен таңдауға болады.
  • Аккаунт (email, аты) — тек тіркелгенде; Hatim/синхрондау үшін.
  • Кamera / сурет — тек пайдаланушы халал/штрихкод тексеруін бастағанда; сурет AI/API арқылы өңделуі мүмкін.
  • AI мәтін сұраулары — пайдаланушы енгізген мәтін backend-ке жіберілуі мүмкін.

Жарнама ID жиналмайды. Намаз ескертулері құрылғыда жергілікті жоспарланады.

2. Деректер қалай қолданылады

  • Намаз уақыты, құбыла, халал каталог/карта
  • Аккаунт және оқу прогресін синхрондау
  • Пайдаланушы сұраған AI/фото тексеру

3. Бөлісу және сақтау

Деректер HTTPS арқылы api.rahatomir.com серверіне жіберіледі. Үшінші тарап жарнама желілеріне сатылмайды. Кamera суреті тек пайдаланушы бастаған тексеру кезінде API-ге жіберілуі мүмкін.

4. Пайдаланушы таңдауы

  • Орналасу, camera, хабарландыру рұқсаттарын жүйеден өшіруге болады.
  • Аккаунтсыз негізгі мазмұн қолжетімді (AI — prod-та логин қажет болуы мүмкін).
  • Аккаунтты жою/деректерді өшіру — Баптаулар немесе қолдау арқылы.

5. Балалар

Қолданба 13 жасқа дейінгі балаларға арналған негізгі аудитория емес.

6. Байланыс

Сайт: rahatomir.com
API: api.rahatomir.com

Политика конфиденциальности (кратко, RU)

Приложение RAHAT OMIR обрабатывает ограниченные данные: геолокацию (если разрешено), данные аккаунта при регистрации, фото/камеру только по инициативе пользователя для halal-проверки, текст AI-запросов. Данные передаются по HTTPS на api.rahatomir.com, не продаются рекламным сетям. Уведомления о намазе планируются локально на устройстве.
